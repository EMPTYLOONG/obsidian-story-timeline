# Story Timeline

> 舷窗式可自定义时间线插件，为剧本创作、世界观设定、历史叙事而生。

一个为 Obsidian 打造的横向时间线视图。支持多轨道分类、时期事件、子事件分割、标签筛选、时间游标、可视化编辑器、自定义代表色、无极缩放和带时间区间的图片导出。

---

## ✨ 功能一览

### 时间线视图
- **多轨道布局**：每个分类一条水平轨道，互不干扰
- **舷窗式视口**：横向滚动查看任意长的时间跨度（从公元前到未来）
- **无极缩放**：`0.5×` 到 `500×` 连续缩放，刻度从**周**到**10 年**自适应切换
- **时间刻度**：粘性固定在顶部，点击刻度激活游标
- **重叠自动分层**：同轨道内时间重叠的事件自动纵向错开，不互相遮挡
- **内容自适应高度**：卡片高度按内容自动计算

### 事件类型
- **单点事件**：某一时刻发生的事（如「卢沟桥事变」）
- **时期事件**：持续一段时间的事（如「张三的一生 1900–1980」）
- **子事件**：时期内部的阶段划分，按时间比例自动对齐到父事件条带上

### 视觉样式
- **分类颜色**：每个分类有一个代表色，作为该轨道事件的默认颜色
- **事件自定义色**：可以为单个事件设置独立颜色，覆盖分类色
- **子事件对比**：子事件块使用更深的半透明色，与父条带背景形成层次

### 交互
- **时间游标**：点击时间刻度，激活蓝色游标线
- **时长徽章**：所有包含游标时间的时期事件显示「已过 X 年 Y 个月」，并**粘在视口左侧**直到离开
- **粘性内容**：时期条带滚动时，其文字内容保持在视口左侧可见
- **卡片宽度调节**：工具栏右侧滑条实时调整

### 数据管理
- **可视化编辑器**：点「+ 新建事件」或右键卡片，表单式填写
- **自动注册分类**：笔记里写新 `timelineCategory`，刷新后自动加入设置列表
- **智能名称匹配**：`timelineCategory: 反派线` 自动重定向到对应分类
- **重复检测**：设置面板高亮显示名重复的分类
- **名称长度限制**：分类显示名称最长 20 字符
- **二次确认**：新建 / 删除分类时弹出确认框
- **模糊日期**：支持 `2024`、`2024-03`、`2024-03-15`、`2024年3月15日`、`618`、`-500`
- **自动刷新**：笔记改动后视图自动更新（400ms 防抖）

### 筛选与导出
- **分类筛选**：点击分类 chip 隐藏/显示整条轨道
- **标签筛选**：点击标签 chip 隐藏含该标签的事件
- **自定义区间导出**：可指定起止日期，只导出该时间段
- **导出内容可选**：可选是否包含描述、标签、子事件
- **智能边界处理**：跨边界卡片在左边缘显示粘性信息 + 「已过 X」徽章

## 📦 安装

### 从 GitHub Release 安装（推荐）

1. 从 [最新 Release](https://github.com/EMPTYLOONG/obsidian-story-timeline/releases/latest) 下载三个文件：
   - `main.js`
   - `manifest.json`
   - `styles.css`

2. 在你的 Obsidian 库中，把这三个文件放入：
   ```
   <你的库>/.obsidian/plugins/story-timeline/
   ```

3. 重启 Obsidian → **设置 → 第三方插件** → 启用 **Story Timeline**

### 从源码安装（开发者）

```bash
cd <你的库>/.obsidian/plugins/
git clone https://github.com/EMPTYLOONG/obsidian-story-timeline.git story-timeline
cd story-timeline
npm install
npm run build
```

## 🚀 快速开始

### 1. 打开时间线

- 点击左侧 Ribbon 区域的 **⏰ 时钟图标**
- 或按 `Ctrl/Cmd + P` 打开命令面板 → 搜索「打开故事时间线」

### 2. 创建第一个事件

点击工具栏 **+ 新建事件** 按钮，填写表单：

```
标题：      第一幕：主人公离家
开始日期：  2024-03-15
结束日期：  （留空 = 单点事件）
分类：      主线
代表色：    （可选，留空则用分类颜色）
标签：      转折, 开场
描述：      主角被迫离开故乡，踏上旅程
```

保存后事件自动出现在时间线上。

### 3. 打开右侧面板查看

时间线以右侧边栏形式打开，可与笔记同时查看，窗口可拖动调整宽度。

## 📖 Frontmatter 字段参考

所有字段写在笔记最顶部的 frontmatter 里。**只有 `timelineDate` 是必需的**。

```yaml
---
# ===== 必需 =====
timelineDate: 2024-03-15            # 开始日期

# ===== 时期（可选） =====
timelineEndDate: 2024-06-20         # 结束日期，填写后变时期条带

# ===== 显示内容（可选） =====
timelineTitle: 第一幕：离家          # 不填则用文件名
timelineDescription: 主角踏上旅途    # 描述（显示在标题下方）
timelineCategory: main              # 所属分类
timelineColor: "#8e44ad"            # 事件自定义颜色（覆盖分类色）
timelineTags: [转折, 开场]          # 标签

# ===== 子事件（可选） =====
timelineSubEvents:
  - date: 2024-03-15
    endDate: 2024-04-01
    title: 序章
    link: 序章笔记           # 可选，点击跳转
  - date: 2024-04-01
    endDate: 2024-06-20
    title: 正篇
---
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `timelineDate` | 日期字符串 | **必需**。事件开始日期 |
| `timelineEndDate` | 日期字符串 | 结束日期，填写后变时期条带 |
| `timelineTitle` | 字符串 | 事件标题 |
| `timelineDescription` | 字符串 | 事件描述 |
| `timelineCategory` | 字符串 | 所属分类（对应轨道） |
| `timelineColor` | 颜色字符串 | 事件自定义色（如 `"#8e44ad"`）。**必须用引号** |
| `timelineTags` | 数组 / 字符串 | 自定义标签 |
| `timelineSubEvents` | 数组 | 子事件列表 |

> ⚠️ **`timelineColor` 必须用引号包裹**：YAML 中 `#` 是注释符，不加引号会被当作空值。

### 日期格式支持

| 写法 | 精度 | 示例 |
|---|---|---|
| `2024-03-15` | 日 | 精确到天 |
| `2024/3/15` `2024.3.15` | 日 | 斜杠/点分隔 |
| `2024年3月15日` | 日 | 中文 |
| `2024-03` `2024年3月` | 月 | 锚定到该月 1 日 |
| `2024` `2024年` | 年 | 锚定到该年 1 月 1 日 |
| `618` | 年 | 唐朝建立 |
| `-500` | 年 | 公元前 500 年 |

无法解析的日期会在开发者控制台给出警告并跳过该事件，**不影响其他事件**。

## 🎨 界面说明

### 工具栏

| 按钮 | 作用 |
|---|---|
| **+ 新建事件** | 打开可视化编辑器 |
| **←** / **→** | 视口左右平移 200px |
| **＋** / **－** | 放大 / 缩小时间轴（每次 ×1.25） |
| **刷新** | 重新扫描所有笔记 |
| **导出图片** | 打开导出对话框 |
| **清除游标** | 取消时间游标 |
| **缩放级别** | 显示当前缩放倍数 |
| **宽度滑条** | 调整卡片宽度（60–240px） |

### 无极缩放

支持两种操作方式：

1. **点 ＋ / － 按钮**：每次缩放 1.25 倍
2. **Ctrl/⌘ + 鼠标滚轮**：在时间线视口上连续缩放

缩放范围 **0.5× 到 500×**，刻度自动切换：

| 缩放级别 | 刻度间隔 | 显示格式 |
|---|---|---|
| 极高 | 每周 | `2024-W12` |
| 高 | 每两周 | `2024-W12` |
| 中高 | 每月 | `2024-01` |
| 中 | 每季度 | `2024 Q1` |
| 中 | 每半年 | `2024 H1` |
| 中低 | 每年 | `2024` |
| 低 | 每 5 年 | `2000` `2005` |
| 极低 | 每 10 年 | `2000` `2010` |

### 筛选栏

工具栏下方分两组：

```
分类  [主线] [支线] [角色线] [其他]
标签  [主角] [伏笔] [战争] [已回收]        [重置]
```

- 点击 chip → **隐藏**该类事件（chip 变灰带删除线）
- 再次点击 → 恢复显示
- 点 **重置** → 恢复所有

### 卡片右键菜单

右键任意卡片：

- **编辑事件**：打开编辑器
- **打开笔记**：跳转到对应笔记
- **从时间线移除**：清空笔记里的 timeline* 字段（笔记内容保留）

## 🖼 导出图片

点工具栏 **导出图片** 打开对话框：

```
┌─────────────────────────────────────────┐
│ 导出时间线截图                            │
│                                          │
│ 时间区间（可选）                          │
│ 留空则包含全部事件。                      │
│                                          │
│ 开始日期          结束日期                │
│ [2024-01-01]     [2024-12-31]            │
│                                          │
│ 导出内容                                  │
│ ☑ 包含事件描述                            │
│ ☑ 包含标签                                │
│ ☑ 包含子事件                              │
│                                          │
│                     [取消]  [导出]        │
└─────────────────────────────────────────┘
```

### 时间区间

- **留空** → 导出全部事件
- **填写** → 只导出该区间（严格按时间截断）

### 跨边界卡片处理

如果某张时期卡片跨越导出区间边界（例如导出 `1940-1950`，卡片是 `1887-2006`）：

- 卡片会**被截断**到区间内
- **主要信息**（日期、标题、描述、标签、子事件）**粘在图片左边缘显示**
- 日期旁边会出现蓝色胶囊 **「已过 X 年 X 个月」**（从卡片开始到区间左边界的时长）

### 自动降级

如果时间线特别长（几百年跨度），Canvas 尺寸超限时：

- 自动降低 `dpr`（从 2 到 0.5）
- 若最小 `dpr` 仍超限，弹出提示建议缩小时间轴或缩短区间

## ⚙️ 设置面板

**设置 → 故事时间线设置**：

| 项 | 说明 |
|---|---|
| 日期字段名 | frontmatter 中用作日期的字段（默认 `timelineDate`） |
| 默认缩放级别 | 1–500。1 = 10 年间隔，500 = 周间隔 |
| 卡片宽度 | 60–240px |
| 新建事件的默认文件夹 | 留空则放在库根目录 |
| 显示事件描述 | 是否显示 `timelineDescription` |
| 显示事件标签 | 是否显示 `timelineTags` |
| 自动注册新分类 | 见下 |

### 分类管理

每个分类可配置：

- **颜色**：该分类的默认代表色
- **ID**：frontmatter `timelineCategory` 使用的值（只读，超长时省略显示）
- **显示名称**：时间线标签上显示的文本（最长 **20 字符**）

支持**新增**（带二次确认）、**删除**（带二次确认）、**检查重复**。

### 事件代表色 vs 分类颜色

- **分类颜色**：在设置面板中配置，作用于该分类下的所有事件（默认色）
- **事件代表色**：在事件编辑器中为单个事件设置，**优先级更高**

如果事件没设 `timelineColor`，就用分类色；设了则用事件色。想恢复分类色，在编辑器里点颜色选择器右侧的 **↺** 按钮。

### 自动注册新分类

开启时（默认）：笔记中写入新的 `timelineCategory` 值后，刷新时该分类自动加入设置列表，并分配预设颜色。

**智能匹配**：如果新值匹配某个已有分类的**显示名**，会自动重定向到该分类的 ID，不产生重复。

## 💡 使用技巧

### 人物一生的写法

```yaml
---
timelineDate: 1900-01-01
timelineEndDate: 1980-06-15
timelineTitle: 张三
timelineCategory: character
timelineTags: [主角, 已故]
timelineSubEvents:
  - date: 1900-01-01
    endDate: 1915-01-01
    title: 童年
  - date: 1915-01-01
    endDate: 1940-01-01
    title: 青年
  - date: 1940-01-01
    endDate: 1960-01-01
    title: 中年
  - date: 1960-01-01
    endDate: 1980-06-15
    title: 老年
---
```

配合**时间游标**：点击 1960 年的刻度 → 徽章显示「已过 60 年」，即 60 岁。

### 标签体系建议

| 维度 | 示例标签 |
|---|---|
| 角色归属 | `张三` `李四` `王五` |
| 线索状态 | `伏笔` `回收` `悬念` |
| 剧情类型 | `战斗` `对白` `闪回` `内心` |
| 修改状态 | `待改` `已定稿` |
| 情感基调 | `高潮` `低谷` `转折` |

标签搭配**筛选器**，可快速查看某一类事件的时间分布。

### 用颜色突出关键事件

比如用**金色**标记每幕的转折点，用**深红**标记死亡事件：

```yaml
timelineColor: "#f39c12"     # 金色
timelineColor: "#c0392b"     # 深红
```

这样即使事件属于同一个分类，视觉上也能一眼分辨出不同类型的节点。

### 分期管理一条线

1. 用**大时期**表示整条线（如「王朝兴衰 618 → 907」）
2. 用**子事件**表示各阶段（「贞观之治」「安史之乱」）
3. 每个子事件用 `link` 指向详细笔记

### 导出某一段时间的快照

比如想给朋友看 1940 年代的剧情：

1. 点 **导出图片**
2. 开始日期填 `1940`，结束日期填 `1950`
3. 导出 → 得到 1940–1950 的 PNG

跨越区间的长卡片会自动"左对齐"显示关键信息，方便阅读。

## ❓ 常见问题

### 时间线显示不出事件

1. **frontmatter 是否在第一行？** 第一行必须是 `---`，前面不能有空行
2. **日期格式是否正确？** 见上文
3. **是否点了刷新？** 或关闭再打开视图
4. **打开开发者控制台**（`Ctrl/Cmd + Shift + I`）看 Console 是否有红色报错

### 卡片挤在一起

- 用 **Ctrl+滚轮** 或 **＋** 放大时间轴
- 重叠的事件会自动分层，不需要手动处理

### 日期解析失败

支持的格式有限。常见错误：

| ❌ 不支持 | ✅ 改用 |
|---|---|
| `二〇二四年` | `2024` |
| `2024 年 3 月` | `2024-03` |
| `明年三月` | `2025-03` |
| `光绪二十年` | `1894` |

失败的事件会在 Console 里输出警告，但**不影响其他事件**。

### 事件自定义颜色不生效

**最常见的原因**：frontmatter 里 `timelineColor` 没有加引号。

```yaml
timelineColor: #8e44ad      # ❌ YAML 把 # 当注释，值为 null
timelineColor: "#8e44ad"    # ✅ 正确
```

用**事件编辑器**设置颜色会自动加引号，不会出问题。手动编辑 frontmatter 时记得加引号。

### 分类名称有长度限制

显示名称最长 **20 字符**，超过会被自动截断。如需修改，编辑 `src/settings.ts` 里的：

```typescript
const MAX_CATEGORY_LABEL_LENGTH = 20;
```

### 显示名重复的分类

两个分类显示名相同 → 时间线上会有两条同名轨道。

**解决**：在设置里修改其中一个的**显示名称**。

**预防**：自动注册时会做**名称匹配**，笔记里写的若是某个分类的显示名，会自动重定向到它的 ID。

### 卡片高度不够，文字被裁

修改 `src/TimelineView.ts` 顶部的两个常量：

```typescript
private readonly LANE_UNIT_HEIGHT = 160;  // 空轨道高度
private readonly MIN_CARD_HEIGHT = 130;   // 内容少时卡片的最小高度
```

推荐值：

| 风格 | LANE_UNIT_HEIGHT | MIN_CARD_HEIGHT |
|---|---|---|
| 紧凑 | 130 | 110 |
| 默认 | 160 | 130 |
| 宽松 | 200 | 160 |

### 导出图片失败

如果时间线特别长（几百年跨度），会弹出提示：

```
时间线太长（52000×800px），超出浏览器 Canvas 尺寸上限（16000px）。
建议：点击工具栏「－」缩小时间轴，或隐藏部分分类后再导出。
```

**解决**：

- 缩小时间轴
- 或缩短导出区间
- 或隐藏暂时不需要的分类
- 插件会自动降低 `dpr`（从 2 降到 0.5）来适配

### 导出时卡片被截断

**这是预期行为**。当你指定了导出区间时，跨边界的卡片会被截断到区间内。

被截断的卡片**不会丢失信息**：

- 日期、标题、描述、标签会**粘在图片左边缘显示**
- 日期旁边有蓝色「已过 X」徽章
- 子事件也按时间比例显示在可见区域

### 修改代码后 Obsidian 没反应

- 确认 `npm run dev` 正在运行
- 手动在设置里**关闭再打开**插件
- 装了 Hot Reload 插件的话，看它是否已启用

## 🛠 开发

### 环境要求

- Node.js v18+
- npm

### 本地开发

```bash
git clone https://github.com/EMPTYLOONG/obsidian-story-timeline.git
cd obsidian-story-timeline
npm install
npm run dev      # 监听模式
```

把项目文件夹放到库的 `.obsidian/plugins/` 下，在 Obsidian 中启用。

```bash
npm run build    # 会跑 tsc 做类型检查，然后 esbuild 打包
```

```
story-timeline/
├── src/
```
